# Bubble Sort (Ruby)

A Ruby implementation of bubble sort, written for The Odin Project > Basic Ruby Projects.

## Usage

```ruby
bubble_sort([4, 3, 78, 2, 0, 2])
# => [0, 2, 2, 3, 4, 78]
```

## Behavior

- Returns the sorted array in place (overwrites passed array)
- Handles empty arrays, single elements, duplicates, and negative numbers
- Time complexity: O(n²) worst case
